Organize your income and expenses, recording every movement with a focus on simplicity and your privacy.

### ✨ Flow Balance Installation Guide

Flow Balance is downloaded directly from its official source on GitHub (**Sideloading**). To avoid security risks, always download only from the official `zmr-software` link.

#### 1. Choose the Right Version for Your Device
* **arm64-v8a (Recommended):** For modern Android smartphones.
* **x86_64:** For modern Chromebooks.
* **other:** Compatible with virtually any Android phone.

#### 2. Installation Steps
1. **Visit the Official Site:** Go to the [GitHub Releases](https://github.com/zmr-software/FlowBalance/releases) page.
2. **Download the File:** Tap the appropriate `.apk` file `(Choose the Right Version for Your Device)` to start downloading.
3. **Authorize Installation:** If your system prompts a security warning regarding unknown sources, open Settings and toggle "Allow from this source".
4. **Install:** Return to the downloaded file, tap Install, and open the app to get started.

### ✨ Guía de Instalación de Flow Balance

Flow Balance se descarga directamente desde su fuente oficial en GitHub mediante **Sideloading**. Para evitar riesgos de seguridad, descarga siempre exclusivamente desde el enlace oficial de `zmr-software`.

#### 1. Elige la Versión Correcta para tu Dispositivo
* **arm64-v8a (Recomendado):** Para smartphones Android modernos.
* **x86_64:** Para Chromebooks modernos.
* **otro:** Compatible con cualquier teléfono Android.

#### 2. Pasos para la instalación
1. **Entra a la web oficial:** Ve a la página de [Lanzamientos en GitHub](https://github.com/zmr-software/FlowBalance/releases).
2. **Descarga el Archivo:** Toca el archivo `.apk`, `(Elige la Versión Correcta para tu Dispositivo)` para comenzar la descarga.
3. **Autoriza la Instalación:** Si el sistema muestra un aviso de seguridad sobre fuentes desconocidas, ve a Ajustes y activa "Permitir desde esta fuente".
4. **Instala la Aplicación:** Regresa al archivo descargado, presiona Instalar y abre la aplicación para empezar.
